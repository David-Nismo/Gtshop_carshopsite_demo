# GT SHOP KZ — демо интернет-магазина

Адаптивный статический каталог автомобильного тюнинга и аксессуаров.

## Текущее состояние
- 50 карточек в каталоге.
- 38 карточек основаны на найденных товарах JPM (позиции 1–8 и 21–50).
- Позиции 9–20 — демонстрационные идеи, отмечены бейджем «Демо» и не являются реальными предложениями продавца.
- Карточки с реальным источником ведут на исходную страницу товара или категорию.

## Запуск
- Открой `index.html` в браузере.
- Для локального сервера используй VS Code + Live Server.
- Публикация: GitHub Pages из ветки `main`.

Цены в карточках — снимки каталога на момент проверки, не live-прайс. Наличие, стоимость, доставка и совместимость требуют подтверждения у продавца. Полный ассортимент JPM пока не перенесён; на главной есть ссылка на каталог магазина.

## Backup
Полная резервная копия состояния сайта до расширения каталога: `backup/2026-10-28/`. В папке сохранены `app.js`, `index.html`, `styles.css` и копия всех файлов из `assets/`. Для отката скопируй резервные файлы обратно в корень репозитория. Данные корзины и избранного из localStorage не входят в резервную копию.

## Ограничения демоверсии
- Корзина и избранное хранятся в localStorage текущего браузера.
- Онлайн-оплата, серверный склад и синхронизация с продавцами не подключены.
- Не оформляй реальный заказ только на основании демонстрационной карточки.
