# GT SHOP KZ — демо интернет-магазина

Адаптивная демоверсия магазина автомобильных аксессуаров и тюнинга в тёмном стиле с красными акцентами.

## Как запустить
- Открой `index.html` в браузере.
- Или открой папку в VS Code и запусти через расширение Live Server.
- Для публикации: GitHub → **Settings → Pages** → **Deploy from a branch** → branch `main`, folder `/(root)` → **Save**. После публикации GitHub покажет URL сайта в разделе Pages.

## Что есть в демо
- Главная страница, каталог и страницы отдельных товаров.
- Поиск, фильтрация по категориям и сортировка.
- Корзина с изменением количества и удалением позиций.
- Избранное.
- Демо-оформление заказа и локальная история заказов.
- Демо-профиль.
- Страницы доставки и контактов.
- Адаптация под мобильные экраны.

## Важно
Это **статическая frontend-демоверсия**, не production-магазин. Корзина, избранное, профиль и демо-заказы хранятся только в `localStorage` текущего браузера. Нет настоящей авторизации, базы данных, отправки заказов продавцу и платёжной системы. Не вводи реальные пароли или банковские данные.

Товары, цены и наличие приведены только для демонстрации. Фотографии загружаются с Unsplash и требуют интернет-соединения. Перед коммерческим запуском нужно подключить backend, безопасную авторизацию, защищённое управление остатками и серверное оформление заказов.

Названия, цены и характеристики части товаров сверены с публичными карточками JPM Tuning Market ([jpm.kz](https://jpm.kz/)). Для кованых дисков использован материал JPM о дисках под заказ. Проект — независимый учебный прототип и не является официальным сайтом JPM. Наличие и цены могут меняться; актуальные сведения проверяйте на страницах источника.
