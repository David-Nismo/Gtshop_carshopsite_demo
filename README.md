# GT SHOP KZ — демо интернет-магазина

Адаптивный статический каталог автотюнинга и аксессуаров. Каталог содержит 50 карточек: товары с источниками JPM Tuning Market и несколько демонстрационных позиций для оформления.

## Запуск
- Открой `index.html` в браузере.
- Для локального сервера можно использовать VS Code + Live Server.
- Публикация: GitHub Pages из ветки `main`.

## Каталог и источники
- [Полный каталог JPM](https://jpm.kz/collection/all)
- [Диски и аксессуары для колёс JPM](https://jpm.kz/collection/diski)
- [Аксессуары JPM](https://jpm.kz/collection/aksessuary)
- [Автотовары Kaspi](https://kaspi.kz/shop/c/car%20goods/)

У карточек, перенесённых из JPM, есть ссылка на исходный товар или соответствующую категорию. Фотографии привязаны к карточкам по источникам магазина. Цены в проекте являются снимками каталога, а не live-прайсом; наличие, стоимость, применимость и доставка должны подтверждаться продавцом. Часть товаров 9–20 остаётся демонстрационной и так помечена.

## Backup
Снимок исходного сайта до расширения каталога находится в `backup/2026-10-28/`:
- `app.js`
- `index.html`
- `styles.css`
- `README.md`

В резервной папке сохранены исходные текстовые файлы; изображения из `assets/` не дублируются и остаются в корне репозитория. Для отката скопируй три резервных файла обратно в корень. Данные корзины и избранного из localStorage в резервную копию не входят.

## Ограничения демоверсии
- Корзина, избранное и пользовательские данные хранятся в localStorage текущего браузера.
- Онлайн-оплата, серверный склад и синхронизация с продавцами не подключены.
- Не оформляй реальный заказ только на основании демонстрационной карточки.
