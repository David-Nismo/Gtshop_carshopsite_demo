# Полный импорт каталога JPM

Импортёр наполняет GT SHOP KZ реальными карточками JPM: оригинальными названиями, URL, изображениями, распознанными ценами, отметками наличия и датой импорта.

## Запуск на Windows 11

1. Установи Node.js 20 или новее.
2. Склонируй репозиторий и открой терминал в его корне.
3. Убедись, что автоматический доступ разрешён правилами сайта и его robots.txt.
4. Запусти:

\`\`\`powershell
node catalog-import/import-jpm.mjs
\`\`\`

Скрипт обновит catalog-import/jpm-products.js и catalog-import/import-report.json. Проверь несколько карточек и отчёт, затем закоммить изменения в GitHub. Данные уже подключены в index.html перед app.js и попадут в общий поиск и каталог.

Настройки:
- Увеличить паузу: $env:JPM_DELAY_MS=700
- Для короткого теста: $env:JPM_MAX_PAGES=2

## Охват и ограничения

Импортёр обнаруживает категории из карты сайта и дополнительно проверяет основные разделы: сборные модели, одежду, аксессуары, диски, обвесы, двигатель, подвеску, тормоза, трансмиссию, интерьер, электронику, выхлоп, патрубки и 4×4. Дубли объединяются по URL товара.

Это не live-синхронизация: цены и остатки — снимок на дату импорта. Если цена не распознана, она остаётся «по запросу»; если фото не найдено, поле пустое. Совместимость не угадывается. Структура сайта может измениться, поэтому результаты нужно проверить вручную.

Не обходи защиту, ограничения частоты или правила сайта. Если автоматизированный сбор запрещён, запроси у магазина разрешённый экспорт/фид вместо скрейпинга.


## Текущий блокер

Проверочный запуск из GitHub Actions получил от `jpm.kz` HTML-шаблон размером около 1,3 КБ без товарных карточек на всех проверенных категориях. Поэтому импортёр намеренно не создаёт фальшивые товары и завершается с ошибкой. Чтобы завершить полный импорт, нужен разрешённый экспорт магазина в CSV/XML/JSON или доступный официальный фид/API. Не следует обходить антибот-защиту или ограничения магазина.
